# 教师参考：第 10 讲集成学习与 Bootstrapping

## 数据方案选择

本课准备了两套数据，由授课教师二选一；选定后删除课件中另一张数据页（第 3 页或第 4 页），并告诉学生使用哪个文件夹。

| | 方案 A：WDBC（`data/`） | 方案 B：CTG（`data-ctg/`） |
|---|---|---|
| 内容 | 乳腺肿块细针穿刺图像的细胞核特征，569 条，30 个特征 | 胎心监护信号片段的自动分析特征，2126 段 / 352 个录音，21 个特征 |

| 集成 vs 单树 | 明显更好、更稳定 | 明显更好、更稳定 |
| 集成 vs LR / SVM | 不占优：LR、SVM 在验证集上 AUC = 1.000 | 开发集分组 CV 中 RF / GB 的 PR-AUC、balanced accuracy 高于 LR、SVM |

## 预期答案与教学提示

**数据与协议。** WDBC 每行是一个乳腺肿块样本的细胞核形态特征记录；CTG 每行是一段胎心监护信号的分析特征，同一录音被切成多段。`sample_id`、`recording_id` 只用于追踪和分组。标签是数据中的诊断或专家判读，不是未来风险概率。train 用于拟合，validation 用于预先比较，test 在协议锁定后一次揭示。

**A 决策树。** 示例样本（`worst perimeter = 120 > 105.95`，`mean concave points = 0.08 > 0.05`）落到右下叶节点（良 3 · 恶 112），预测恶性概率 112/115 ≈ 0.97。叶节点概率就是训练样本中各类的比例。每个节点在所有特征和候选阈值中选使加权 Gini 不纯度下降最多的切分；Gini = 1 − Σp²，表示随机取两个样本类别不同的概率，越小越“纯”。WDBC 根节点 Gini = 0.467。树越深训练准确率越高（不限深度时为 1.000），验证准确率在深度 3 左右最好（0.974），之后不再提高。对 train 做 10 次 bootstrap，深度 2 树的根节点在 worst perimeter（4 次）、worst area（3 次）、worst radius（2 次）、mean concave points（1 次）之间变化：单棵树偏差低、方差高。树只比较阈值两侧的大小顺序，单调变换不改变切分，所以不需要标准化。

CTG 的深度 2 树：根节点 `Mode ≤ 106`；左支再按 `Max ≤ 234` 切（病理 54 / 其余 3），右支按 `ALTV ≤ 68.5` 切（其余 1164 / 病理 29；ALTV 更高时病理 25 / 其余 2）。10 次 bootstrap 中根节点在 Mode（7 次）和 Mean（3 次）之间变化。

**B 投票与方差公式。** 硬投票是类别计数的多数；软投票是概率平均。样本 B 是“多数票错（判 1）但概率均值 0.48 判对”的情况。平均后的方差 = ρσ² + (1−ρ)σ²/B：B 增大时只降第二项，下限是 ρσ²；ρ 接近 1（模型犯同样的错）时投票几乎没有收益；平均不改变偏差，所以 bagging 用偏差低、方差高的深树。逻辑回归本身方差小，bagging 它几乎没有帮助。

**C Bootstrap、bagging 与 OOB。** 不同样本占比的理论期望是 `1-(1-1/n)^n≈0.632`，袋外比例约 0.368，单次抽样会波动。Bagging 通过训练样本重抽样制造多样性，各树互不依赖，可以并行。OOB：每条记录只由“没抽到它”的那些树来预测，汇总后得到 OOB 误差，可以代替验证集来粗调树数等参数；但它不能代替锁定测试集。方案 B 要特别提醒：OOB 按行抽样，同一录音的其他片段可能在树的训练集里，所以 CTG 的 OOB 准确率（约 0.99）偏乐观，分组数据仍应以分组 CV 为准。

**D 随机森林与特征重要性。** 随机森林在每个节点只从随机抽取的部分特征中选切分，使树彼此更不同，降低 ρ。树数增加后表现进入平台，不会因为树多而过拟合，只是计算变慢。不纯度重要性偏向取值多的连续特征，相关特征会分摊；置换重要性在验证集上计算，相关特征会互相替补。WDBC 中 worst perimeter、area、radius 的不纯度重要性各约 0.12–0.13，但单独置换其中一个时 AUC 下降都不到 0.002。CTG 中不纯度重要性前几名是 Mode、Mean、ASTV、ALTV，置换重要性前几名是 ALTV、DP、ASTV：两种方法排名不同是正常的，应结合相关矩阵解释。

**E Boosting。** Boosting 按顺序更新。AdaBoost 增大错分样本的权重；Gradient Boosting 让下一棵树拟合当前损失的负梯度（二分类 log-loss 下为 y − p），不是只拟合错分样本。WDBC 上 `learning_rate=0.1` 时，验证 log-loss 约在 50 轮最低（0.079），500 轮升到 0.162，而 AUC 几乎不变：过拟合先体现在概率过于自信上，所以轮数应由验证集或 early stopping 决定。学习率越小需要越多轮。XGBoost、LightGBM 本质都是梯度提升树：XGBoost 在目标函数中加入树复杂度正则并利用二阶导信息，二者都更快，并能直接处理缺失值。

**F 公平比较与选型。** 见下方参考结果。方案 A 的预期结论是“树集成大幅改善单树，但不胜过 LR / SVM”；方案 B 的预期结论是“RF / GB 在 PR-AUC、balanced accuracy 上胜过 LR / SVM，但单一验证集上 LR 的 AUC 与 RF 接近，要看分组 CV”。两种结论都应写出差距是否大于折间波动。

**G 稳定性与不确定性。** Bootstrap 训练预测的 SD 描述“训练样本扰动下的预测变化”。固定已拟合模型后对测试索引重抽样得到的指标区间，不能覆盖重新训练、重新选模型或外部人群变化。只需让学生说清这三者不是一回事，不必展开计算。

**H 对照表。** Bagging：并行；每轮用一份 bootstrap 样本；深树；主要降方差；对噪声较稳健，树多不过拟合；关键参数是树数、max_features。Boosting：顺序；每轮改变样本权重或拟合负梯度；浅树；主要降偏差；对噪声和轮数敏感；关键参数是 learning_rate × n_estimators、max_depth。

## 教师追问

翻转课堂抽到学生后，可从下列问题中挑 2–3 个追问：

1. 叶节点给出的“概率”是怎么算的？树越深，这个概率会变得怎样？
2. 为什么随机森林用不剪枝的深树，而 AdaBoost 常用只切一次的树桩？
3. 树越多，随机森林会过拟合吗？boosting 轮数越多呢？
4. 方差公式里的 ρ 指什么？随机森林用什么办法降低它？
5. OOB 误差是怎样算的？在方案 B 这种同一录音有多个片段的数据上，它为什么偏乐观？
6. 为什么树模型不需要标准化，而你的 LR、SVM 需要？标准化应该在哪一步拟合？
7. 两个高度相关的特征，在不纯度重要性和置换重要性里分别会怎样？
8. XGBoost 和 sklearn 的 GradientBoosting 是什么关系？
9. 你的集成模型比逻辑回归高了多少？这个差距比交叉验证的折间波动大吗？
10. 如果下一份数据来自另一家医院，你现在的结论里哪一句不再成立？

## 课堂流程

1. 课件第 1–4 页：提出问题，介绍选定的数据方案（第 3 页或第 4 页二选一）。
2. 第 5–6 页：第一个知识点决策树，让学生读示例树、讨论深度与不稳定。
3. 第 7–9 页：手算投票和一次 bootstrap 抽样，讲“集成为什么有效”的方差公式和 OOB。
4. 第 10–11 页：随机森林的特征随机化与 boosting 的顺序依赖。
5. 第 12–14 页：常用实现与超参数、特征重要性、选型经验。
6. 第 15–19 页：公平比较协议、稳定性与不确定性、学生产出、工作流与证据边界。

## 评分建议

定义与手算 25%；实验协议与公平比较 25%；机制解释 30%；证据边界与后续建议 20%。不按最高 accuracy、图表装饰或是否选择教师同一模型评分。

## 重要限制

方案 A 缺少患者分组与时间信息，不能证明患者独立性。方案 B 已按录音文件分组，但录音文件不一定等于孕妇个体，也缺少外部中心数据。两套数据都不能证明跨医院泛化、诊断效用或因果关系。特征重要性是模型依赖的预测解释，不是生物医学因果效应。
