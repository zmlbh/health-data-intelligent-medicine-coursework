# 第 10 讲：集成学习与 Bootstrapping（wang）


## 1. 定位、学习目标与产出

课程类型：算法选择 + 模型改进，辅以重抽样不确定性估计。核心问题是“多个弱模型如何组合成更稳定的强模型？”

学生最终需要在给定的数据上做实验，理解集成学习和 bootstrap 方法。第一个要学的知识点是决策树（集成方法的基学习器），主线是“平均降低方差”：单棵深树偏差低、方差高，bagging 和随机森林通过平均降低方差，boosting 通过顺序叠加浅树降低偏差。核心概念还包括：聚合机制、抽样机制、模型稳定性、三模型公平比较、boosting 机制和验证边界，以及超参数、OOB、特征重要性和选型等应用知识。

概念簇：C0 决策树；C1 集成与多样性（含方差公式）；C2 bootstrap 与 bagging（含 OOB）；C3 随机森林；C4 boosting（含 XGBoost / LightGBM）；C5 稳定性与不确定性；C6 公平比较、优点与局限；C7 应用：超参数、特征重要性与选型。课程大纲目标与课件、工作单的对应见第 4 节。

## 2. 总问题与完整探究问题

数据：研究团队使用一套生物医学表格数据比较分类算法。默认方案 A 为乳腺肿块细针穿刺图像的细胞核特征（良恶性）；备选方案 B 为胎心监护信号特征（病理型 vs 其余），见第 3 节。

学生需要学习：在同一数据、同一验证协议下，如何组合模型并检验其收益，形成兼顾分类表现、稳定性、解释负担与证据边界的研究方案？

| 探究问题 | 必学内容 | 学生行动与个体输出 | 对总问题的贡献 |
|---|---|---|---|
| Q0 一棵决策树怎样预测，为什么不稳定？ | 切分、阈值、Gini 不纯度、叶节点概率；深度与过拟合；树对尺度不敏感 | 读示例树并手推一个样本的预测；比较不同深度的训练/验证表现；观察 bootstrap 后根节点的变化 | 说明集成要解决的问题：单棵深树偏差低、方差高 |
| Q1 多个模型在什么条件下能改善单模型？ | 硬投票、软投票、加权；模型错误的相关性；弱模型含义；平均后的方差 ρσ² + (1−ρ)σ²/B | 手算同一批样本的多数票与概率均值，比较一致/不一致错误；提交聚合计算表与初步判断 | 解释为什么集成可能有效，也可能无效 |
| Q2 有放回抽样究竟改变了什么，bagging 如何使用它？ | 有放回抽样、重复样本、独特样本、袋外样本；可并行训练 | 标注实际抽样索引，计算不同样本比例；画 bagging 训练流程 | 明确训练数据如何制造多样性 |
| Q3 随机森林比普通 bagging 多了什么随机性？ | 多棵树；样本重抽样；每个节点分裂的候选特征随机化 | 比较单树、全特征 bagging、sqrt 特征森林；记录树错误相关性与聚合表现 | 判断额外特征随机化是否在本数据上有收益 |
| Q4 “稳定”与“不确定性”是否同一件事？ | 训练重抽样后的预测变化；固定模型测试指标 bootstrap 区间 | 解释重复拟合预测波动图和配对区间，填写两个 bootstrap 用途对照表 | 限定稳定性结论和区间可解释的范围 |
| Q5 Boosting 如何逐步改进，与 bagging 有何不同？ | AdaBoost 样本权重；Gradient Boosting 负梯度；learning_rate 与轮数；XGBoost / LightGBM 的正则化梯度提升树思想 | 追踪真实样本的 AdaBoost 权重变化与梯度提升更新，标注顺序依赖；完成三算法机制图与 bagging/boosting 比较 | 给出可替代的模型改进路线及失败条件 |
| Q6 逻辑回归、SVM、随机森林怎样公平比较？ | 同一划分、折内标准化、相同指标；非线性、尺度敏感性；选型经验 | 完成指定三模型课堂练习（加梯度提升）；比较验证与开发集 CV 指标，并说明差距是否大于折间波动 | 判断复杂模型的实际收益，避免先定赢家 |
| Q7 在哪些条件下应改变模型选择或停止扩大结论？ | 解释性、黑箱误用、严格验证；不纯度重要性与置换重要性；机制解释不等于因果解释 | 比较两种特征重要性并结合相关矩阵解释；完成 bagging / boosting 对照表，整合 Q0–Q6 写最终备忘录 | 给出有条件的建议、停止条件与后续验证需求 |

## 3. 候选数据、选择与初步证据

本课准备两套数据，由授课教师二选一：方案 A（WDBC，`data/`）与第 11、12 课衔接，现象是“集成胜过单树但不胜过 LR / SVM”；方案 B（CTG，`data-ctg/`）能看到“集成胜过单树，也胜过 LR / SVM”。

### 方案 A：WDBC

选择 sklearn 内置 Breast Cancer Wisconsin (Diagnostic)，简称 WDBC：

- 观察单位：一条乳腺肿块细针穿刺样本的图像特征记录；不是一颗细胞一行。缺少可用的患者分组与时间字段，不能从本载入表核验患者独立性。
- 已实际核验：569 条记录，30 个连续预测特征，0 个缺失单元格，0 条重复特征行。
- 变量语义：10 类细胞核形态量的 mean、standard error、worst 汇总；不把标签或标识当特征。
- 原载入标签 0=恶性、1=良性；实验显式重编码为恶性=1、良性=0。恶性 212 例（37.3%），良性 357 例（62.7%）。
- 来源：https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic ，DOI：https://doi.org/10.24432/C5DW2B 。本地 sklearn 数据说明已核实来源。
- 加载说明：https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_breast_cancer.html 。课堂可离线加载。
- 授权说明：UCI 的该数据集通常标注 CC BY 4.0；本页未单独复核。正式材料应如实记录核验状态及来源、作者，不把软件许可证当作数据许可证。
- 适配原因：数据小、标签清晰、连续变量尺度不同且存在相关形态指标，可以支持树聚合、特征随机化、单位变换、模型比较与重抽样。无需另添教学主数据。

临时实验采用 seed=1010，分层划分 455 例开发集与 114 例留出测试集。只在开发集运行共享五折 CV，预设参数且不调参，测试集没有被评估。版本：sklearn 1.8.0。

| 模型 | 开发集 ROC-AUC 均值 | 折间 SD | 恶性敏感度均值 |
|---|---:|---:|---:|
| Logistic regression（标准化） | 0.9948 | 0.0052 | 0.9529 |
| SVM（RBF，标准化） | 0.9955 | 0.0066 | 0.9471 |
| 单棵决策树 | 0.9301 | 0.0116 | 0.9059 |
| Bagging（100 棵，全特征） | 0.9906 | 0.0098 | 0.9412 |
| Random forest（100 棵，sqrt 特征） | 0.9938 | 0.0056 | 0.9412 |
| AdaBoost（50 个树桩） | 0.9929 | 0.0059 | 0.9176 |
| Gradient boosting（100 阶段） | 0.9929 | 0.0059 | 0.9294 |

折间 SD 仅为描述量，不是置信区间，也不足以单独证明训练稳定性。数据初步支持“树聚合改善单树，但复杂模型未必胜过简单基线”的开放探究，不据此预设最终答案。

1,000 次对 455 例有放回抽样，每次抽 455 次：不同样本占比平均 0.63184，理论期望 1-(1-1/455)^455=0.63253。袋外比例约 36.8%，是平均规律，不是每次固定数值。

在固定划分（train 341 / validation 114）上，LR 与 SVM 的验证 AUC 均为 1.000，集成方法为 0.994–0.998，单树 0.953；30 次 bootstrap 重训后验证样本的类别翻转率为单树 24.6%、bagging 15.8%、随机森林 7.0%。本数据的特征高度冗余（21 对 |r| > 0.9），随机森林与 bagging 几乎无差别。

### 方案 B：CTG

UCI Cardiotocography（https://archive.ics.uci.edu/dataset/193/cardiotocography ，DOI 10.24432/C51S4N，CC BY 4.0，2026-11-08 核对）：

- 观察单位：一段胎心监护信号片段的自动分析特征；2126 段来自 352 个录音文件，同一录音的片段必须在同一集合。
- 已实际核验：21 个连续特征，0 个缺失；专家判读 NSP 中病理型 176 段（8.3%），课程标签为 `pathologic=1`。
- 划分：`StratifiedGroupKFold` 按录音分组，train 1279 / validation 424 / test 423，seed=1010。
- 初步证据（开发集五折分组 CV）：随机森林 AUC 0.994、PR-AUC 0.944、balanced accuracy 0.925；逻辑回归 0.990、0.923、0.872；RBF-SVM 0.980、0.875、0.797；单树 0.866 ± 0.114。随机森林明显好于 bagging（AUC 0.978）。单一验证集上 LR 的 AUC（0.994）与 RF（0.996）接近，结论应以分组 CV 为准。
- 详细说明见 `data-ctg/README.md`，两套数据的参考结果见 `teacher-reference.md`。

## 5. 分析方案与核心证据

E0 决策树：用 train 拟合 max_depth=2 的示例树，读出切分、阈值和叶节点比例；比较不同深度的训练 / 验证表现；对 train 做 bootstrap 后观察根节点变化，说明单棵树的方差。

E1 抽样索引与不同样本比例：提供 10 条真实开发集记录的小型手算例及 455 例总体的 1,000 次模拟。展示重复、遗漏与有放回过程。袋外机制作为解释 bootstrap 的支持概念，不拓展为独立调参课程。

E2 聚合证据：开发集内部拟合多个小树，展示同一验证样本上的类别与概率；学生计算多数票、概率均值与给定权重的结果。非均匀权重仅演示计算，不以验证或测试标签拟合权重。区分 RF 默认平均树概率再取类别，与一般“多数票”的概念演示。指出 RF 的充分生长树不一定是弱分类器，弱学习器不是“随意差模型”。

E3 森林机制对照：主性能对照为单树、100 棵 bootstrap 树的全特征 bagging、100 棵 sqrt 特征 RF。额外用同一个 RF 实现的 max_features=1.0 与 sqrt 对照尽量隔离特征随机化；树数取 1/10/50/100。记录验证预测、基树错误相关性与聚合表现，不承诺每次单调改善。所有对照仅在开发集内部完成。

E4 训练稳定性：开发集内部再固定一个分层验证子集，从其余训练记录进行 30 次有放回训练重抽样；各方法共享同一轮抽样，单树/bagging/RF 采用固定算法种子以着重观察训练样本扰动。计算固定验证个案恶性概率的重复拟合 SD 与类别翻转率。另用固定训练数据、10 个算法种子区分算法随机性。此分布不是临床个体风险置信区间，也不是测试指标区间。

E5 Boosting：在开发集内部、验证集不参与拟合，追踪少量预先按固定 ID 选定样本的 AdaBoost 前若干轮权重，显示错分者权重上升；Gradient Boosting 用二分类 log-loss 的负梯度 y-p 及阶段预测展示更新方向，不说成只拟合错分样本。比较训练与验证随阶段变化，以讨论继续加树和关注噪声的局限。XGBoost 必须进入学生的机制判断任务，通过官方资料节选与目标函数注释连接到梯度提升、正则化和二阶信息；不强制运行 XGBoost，以保持默认实验离线可用。

E6 公平模型比较：沿用预设 80/20 分层开发/测试划分和共享五折。必做 LR、RBF-SVM、RF，其余模型服务机制问题。LR/SVM 的 StandardScaler 只在每折训练部分拟合，RF 无需标准化。指标为 ROC-AUC、balanced accuracy、恶性 sensitivity、specificity；提供混淆矩阵。SVM 用 decision_function 计算 AUC，不把其分数当概率。阈值采用预设默认预测规则，不用测试集调阈值。不进行为赢得排名的大规模搜索；若后续改为调参，则只能在开发集内增加嵌套验证，须明确变更。

E7 非线性与尺度：固定两个含义易懂的真实特征，拟合仅含这两个特征的 LR、RBF-SVM、RF 辅助模型，画观测范围内响应切片并叠加数据密度，明确它们不等于 30 特征主模型。单位变换选择严格正比例线性转换，固定划分、参数与种子；对比 RF、未标准化 LR/SVM 以及标准化 pipeline。RF 理论上主要依赖次序，但允许浮点与并列分裂导致微小差异。将“树型集成通常不敏感”与“一切 ensemble 都尺度不敏感”区分开。

E8 锁定测试与不确定性：先写定候选模型、评价协议与开发集建议，再拟合开发集并一次性揭示测试结果（方案 A 114 例，方案 B 423 例）。固定所有模型预测后，对同一组测试索引做 2,000 次按类别分层、成对重抽样，报告指标百分位 95% 区间及 RF 相对 LR/SVM 的配对差值区间。每个重抽样索引对全部模型相同。该区间条件于已拟合模型和固定类别数量，不包含重新训练、重新选模型或外部人群变化的不确定性。不能按测试排名继续调参；若与开发集建议冲突，报告不确定并提出新研究。

E9 解释性与综合审计：比较一棵树的路径与森林聚合输出；在开发集内部验证数据上，以 ROC-AUC 为评分重复置换重要性，结合相关特征矩阵解释重要性分摊与波动。重要性不是因果效应。以证据驱动决策矩阵涵盖表现、稳定性、解释成本、验证范围与改变建议的条件，必须引用 Q0–Q7。

核心图表是 E3/E4 的“从单树到 bagging 再到 RF：表现与预测波动对照”，以及 E6 的“LR/SVM/RF 公平比较”。`scripts/demo_ensemble.py` 已实现 E3（树数曲线）、E4（单树 / bagging / RF 的共享重抽样稳定性）、E6（验证表与开发集 CV，方案 B 分组）和 E9 的特征重要性；E1、E2、E5 由学生按工作单自行完成。E7 的响应切片与单位变换、E8 的配对 bootstrap 区间较偏统计细节，作为可选扩展，不是必做内容。
