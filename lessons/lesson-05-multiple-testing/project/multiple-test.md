# 第 6 讲：多重检验校正

> 主题负责人：ji

## 一、课程定位

- **主题**：为什么做很多次检验时，`p < 0.05` 不再可靠？
- **适用对象**：生物医学数据科学、医学统计或科研方法入门学习者
- **建议时长**：课堂 45 分钟；课后作业 60 分钟
- **主题类型**：统计推断、多重比较控制与结果解释
- **先备知识**：假设检验、p-value、显著性水平、效应大小和置信区间

## 二、驱动问题

研究团队同时比较 1,000 个基因在疾病组和对照组中的表达差异。分析结果显示有 53 个基因的原始 p-value 小于 0.05，团队据此宣布找到了 53 个疾病相关基因。

**驱动问题**：当研究者同时进行大量检验时，如何控制假阳性并判断哪些发现值得进一步验证？Bonferroni 和 FDR 应如何选择？

## 三、核心问题

1. 什么是多重检验问题？它来自哪些研究决策？
2. 为什么组学数据尤其容易产生假阳性？
3. 为什么进行 1,000 次检验时，原始 `p < 0.05` 可能产生约 50 个偶然显著结果？
4. Bonferroni、Benjamini–Hochberg FDR 和 q-value 分别控制什么？
5. 如何在控制错误的同时保留发现真实信号的能力？
6. 统计显著性、效应大小、生物学意义和可重复性有什么区别？

## 四、学习目标

完成本讲后，学生能够：

1. 识别同时检验多个基因、临床指标、亚组、模型或终点造成的多重检验问题。
2. 用家族错误率和预期错误发现比例解释多重检验校正的基本思想。
3. 区分原始 p-value、adjusted p-value 和 q-value。
4. 解释 Bonferroni 与 Benjamini–Hochberg FDR 的控制目标、严格程度和适用场景。
5. 通过 1,000 个随机检验的模拟观察未校正和校正后的显著结果数量。
6. 在报告显著结果时同时考虑效应大小、置信区间、生物学机制和独立重复验证。

## 五、关键概念

### 5.1 多重检验的来源

- 同时检验几千个基因、蛋白或代谢物。
- 同时比较多个临床指标、时间点或治疗组。
- 进行多个亚组分析或分层分析。
- 尝试多个模型、特征集合、阈值或终点。
- 先看结果再决定主要分析，也会扩大实际检验次数。

### 5.2 为什么原始 p-value 会失效

单次检验若显著性水平为 `α = 0.05`，在 `H0` 真实成立时出现假阳性的概率约为 5%。当进行很多次独立或近似独立的检验时，至少出现一次假阳性的概率会升高：

`FWER = 1 - (1 - α)^m`

其中 `m` 是检验次数。进行 1,000 次全为随机的检验时，原始 p-value 小于 0.05 的结果平均约有 `1,000 × 0.05 = 50` 个。实际数量会因随机波动、检验相关性和数据结构而变化。

### 5.3 三类 p 值概念

| 概念 | 含义 | 解释边界 |
|---|---|---|
| 原始 p-value | 单个检验在 `H0` 成立时观察到当前或更极端结果的概率 | 未考虑同一分析中其他检验的数量 |
| adjusted p-value | 根据多重检验方法调整后的显著性量，如校正后的 p 值 | 依赖校正方法、检验集合和假设结构 |
| q-value | 与某个结果对应的最小 FDR 阈值，或达到该结果所需的 FDR 水平 | 不是效应大小，也不是结果为真的概率 |

### 5.4 Bonferroni 与 FDR

**Bonferroni correction**：将显著性阈值设为 `α/m`，或将每个 p-value 乘以检验数后截断到 1。它主要控制 family-wise error rate（FWER），即整个检验家族中至少出现一个假阳性的概率。方法简单且严格，适合检验数量较少或假阳性代价很高的确认性研究。

**Benjamini–Hochberg FDR**：将 p-value 从小到大排序，寻找最大的排序位置 `i`，满足 `p_(i) ≤ (i/m)q`，并据此确定显著结果。它控制的是 false discovery rate，即被宣布为发现的结果中假阳性所占比例的期望水平，更适合组学数据和探索性研究。

| 比较维度 | Bonferroni | Benjamini–Hochberg FDR |
|---|---|---|
| 主要控制目标 | FWER | FDR |
| 严格程度 | 通常更严格 | 通常更有检出力 |
| 适用场景 | 少量确认性检验、高错误代价 | 大规模组学、探索性筛选 |
| 代价 | 可能漏掉真实信号 | 允许控制水平内的一定比例假发现 |
| 关键要求 | 预先定义检验家族 | 明确待校正的完整检验集合 |

### 5.5 显著性与生物学意义

- p-value 小不代表效应大。
- 大样本可能使很小的效应达到统计显著。
- 小样本中真实而重要的效应也可能无法达到显著性。
- 应同时报告效应大小、置信区间、adjusted p-value、样本量和验证结果。
- 一个统计发现需要结合生物学机制、独立队列和实验重复来评价。

## 六、常见误区与失败模式

### 常见误区

1. 每个基因都可以独立使用 `p < 0.05` 判断显著。
2. FDR 校正后显著，就说明所有显著基因都是真实的。
3. Bonferroni 永远比 FDR 更科学、更正确。
4. adjusted p-value 小就意味着效应很大或具有临床意义。
5. 只校正最终报告的几个 p-value，却不说明实际尝试过多少检验。

### 失败模式

1. 未预先定义检验家族，导致研究者选择性地报告对自己有利的校正结果。
2. 在多个亚组、终点和模型中反复搜索显著性，产生隐性多重检验。
3. 对相关基因使用不恰当的独立性解释，把一组相关信号当成大量独立证据。
4. 只报告校正后的显著性，不报告效应大小、置信区间和原始检验范围。
5. 将探索性发现写成已确认的生物机制或临床标志物。

## 七、课堂 PBL 流程（45 分钟）

### 7.1 情境导入与初始判断（0–7 分钟）

学生阅读 1,000 个随机基因检验的情境，并回答：

- 如果所有基因都没有真实差异，原始 p-value 小于 0.05 的结果大约有多少？
- 这些结果能否直接称为“疾病相关基因”？
- 哪个证据最可能改变你的判断：效应大小、校正后的 p-value，还是独立重复实验？

### 7.2 多重检验数量识别（7–13 分钟）

学生判断下列研究决策是否会增加检验数量：

| 分析行为 | 是否增加多重检验风险 | 需要说明的对象 |
|---|---|---|
| 同时检验 1,000 个基因 | 是 | 基因检验家族 |
| 比较 5 个临床指标 | 是 | 指标集合 |
| 分析 4 个亚组 | 是 | 亚组与交互作用 |
| 尝试 3 个模型并选择最显著者 | 是 | 模型和终点组合 |
| 预先指定一个主要终点 | 相对较低 | 主要检验及其分析计划 |

讨论：检验家族的定义必须与研究问题和预先分析计划一致，不能只由最终报告的结果决定。

### 7.3 模拟练习 A：1,000 个随机检验（13–23 分钟）

生成 1,000 组没有真实差异的数据，计算每个检验的原始 p-value。

学生记录：

- 原始 p-value 小于 0.05 的数量；
- 使用 Bonferroni 后小于 0.05 的数量；
- 使用 Benjamini–Hochberg FDR（例如 `q = 0.05`）后的数量；
- 重复模拟后数量的均值和波动。

**预期观察**：原始 p-value 通常会出现若干“显著”结果；在全为随机的情形下，Bonferroni 通常很少或没有显著结果，FDR 结果也应受到明显控制，但具体数量随模拟而变化。

### 7.4 模拟练习 B：加入真实信号（23–31 分钟）

在 1,000 个检验中加入一小部分真实效应，比较未校正、Bonferroni 和 BH-FDR 的结果。

学生回答：

1. 哪种方法更容易保留真实信号？
2. 哪种方法对假阳性控制更严格？
3. 当真实效应很小或噪声很大时，校正后的结果如何变化？
4. 结果是否说明 FDR 显著的每个基因都已经被证实？

### 7.5 证据链讨论：从显著到可信（31–39 分钟）

按顺序释放证据：

- **证据 A**：53 个基因的原始 p-value 小于 0.05。可以下什么结论？
- **证据 B**：Bonferroni 后没有基因显著，BH-FDR 后有 8 个基因显著。如何解释差异？
- **证据 C**：8 个基因的效应大小很小，置信区间较宽。统计显著是否等于生物学重要？
- **证据 D**：独立队列只能重复其中 3 个基因。最终报告应如何表述发现等级和结论边界？

每个证据阶段都回答：现在能得出什么、不能得出什么、哪个假设被加强或削弱、还需要什么证据。

### 7.6 退出卡（39–45 分钟）

学生完成以下句子：

- **p-value** 是……，但它不是……；
- **adjusted p-value** 反映……，其解释依赖于……；
- **FDR** 控制……，因此适合……；
- 一个多重检验后的发现要进入后续生物学研究，还需要……。

## 八、课后作业

用自己的话解释以下三个概念：

1. p-value；
2. adjusted p-value；
3. false discovery rate。

### 作业要求

- 为每个概念写出定义、一个组学或临床例子，以及一个不能作出的错误解释。
- 用一个简单例子比较 Bonferroni 和 BH-FDR 的控制目标。
- 说明 1,000 次随机检验为何可能出现约 50 个原始 p-value 小于 0.05 的结果。
- 解释为什么结果报告还需要效应大小、置信区间、生物学机制或独立重复验证。
- 写出一个结论边界：多重检验校正不能自动证明因果关系、临床有效性或所有发现都是真实信号。

### 推荐提交结构

| 部分 | 引导问题 |
|---|---|
| 概念定义 | 这个量在统计上控制或描述什么？ |
| 数学/直觉 | 为什么检验次数增加会改变解释？ |
| 方法比较 | Bonferroni 和 FDR 的错误控制目标有什么不同？ |
| 生物医学例子 | 你的数据中检验家族是什么？ |
| 结果报告 | 应同时报告哪些数值和背景信息？ |
| 结论边界 | 哪些发现仍需独立验证？ |

## 九、评价要点

- 能识别多重检验的来源，并定义合理的检验家族。
- 能解释原始 p-value、adjusted p-value 和 q-value 的区别。
- 能准确区分 FWER 与 FDR 的控制目标。
- 能根据确认性或探索性研究场景选择 Bonferroni 或 BH-FDR，并说明代价。
- 能通过模拟解释随机数据也会产生原始显著结果。
- 能同时考虑效应大小、置信区间、机制和可重复性。
- 结论遵循“主张—证据—推理—边界”，不把统计发现直接写成临床或因果结论。

## 十、教师提示

- 模拟应固定随机种子，并重复多次展示随机波动；不要把“约 50 个”当成每次都必须出现的精确数字。
- 强调 BH-FDR 控制的是发现集合层面的错误比例，不是保证每个显著结果都为真。
- 说明检验之间的相关性和检验家族定义会影响校正结果。
- 让学生同时查看原始 p-value、adjusted p-value、效应大小和置信区间，避免把课程变成单纯的阈值判断。
- 教学数据只用于理解统计控制逻辑，不能据此声称发现了真实疾病机制或临床标志物。

## 十一、收束问题

> 当我看到一组显著 p-value 时，我是否知道一共做了多少次检验、控制了哪一种错误、效应有多大，以及这些发现能否在独立数据中重复？
