# 第 9 讲 PBL 工作计划：SVM 与 Margin（wang）

## 教学定位

通过一个贯穿的真实生物医学例子，让学生在计算、画图和受控干预后理解SVM的定义、方法、优势和限制。问题服务于核心概念，最终解释何时、为何采用某种设置，而非评选“哪个模型好”。

先修：监督分类、训练/验证/测试、分类指标与线性评分。不要求推导对偶优化、KKT或自行实现求解器。

## 核心问题

给定标注样本，SVM怎样定义分类边界、确定边界位置，并处理不能完美分开的数据？margin、support vectors、hinge、C、kernel与gamma如何共同决定模型？

## 知识目标

1. 用f(z)=wᵀz+b解释边界与预测，区分决策分数、几何距离和概率。
2. 用|f|/||w||说明距离归一化，用最大最小距离解释hard margin。
3. 定义支持向量，理解当前解的约束点与患者典型性之间的区别。
4. 用hinge loss和½||w||²+CΣhinge解释soft margin，区分间隔违例与误分类。
5. 理解linear、polynomial、RBF核；区别C的违例权重与gamma的局部作用范围。
6. 理解尺度、验证协议及输入扰动如何影响结论。
7. 根据任务条件解释SVM的优势、局限和合理使用方式。

## 单一案例

使用下载的UCI Vertebral Column真实数据：310条记录、NO100/AB210。AB合并椎间盘突出和脊椎滑脱。预先指定pelvic_incidence与degree_spondylolisthesis两个输入，便于观察二维几何，不代表最佳特征选择。固定分层训练/验证/测试为186/62/62，seed9；不使用测试数据选输入、核或参数。

正式主实验沿用真实标签。人工同坐标相反标签仅用于反事实证明，扰动仅用于扩展，不进入原始数据或正式评价。

## 问题驱动活动

| 活动 | 学生问题 | 实验目的 |
|---|---|---|
| A 数据 | 输入、标签与样本代表什么？ | 明确任务和来源边界 |
| B 几何 | 三条线都分对，如何再区分？ | 分数归一化、最小距离与最大间隔 |
| C 约束 | 删除哪些点会改变边界？矛盾标签怎么办？ | 支持向量与hard/soft margin |
| D 优化 | 增大C改变哪项代价？ | 分开观察hinge、宽度、错误与验证表现 |
| E 相似度 | 核和gamma分别改变什么？ | 固定切片解释函数类和局部范围 |
| F 尺度与泛化 | 换单位为何影响同样的信息？ | 尺度交叉对照、验证选择与测试评价 |
| G 扩展 | 冻结模型后输入扰动如何改变预测？ | 理解特定扰动假设下的敏感性 |

八点可分子集只用于几何定义；完整训练集用于C与核实验。每个活动先预测再运行。控制变量、可观察量和限制见[实验设计](experiment-design.md)。

## 协议与解释要求

训练scaler与SVC组成Pipeline。删除点实验冻结scaler。线性C∈{.01,.1,1,10,100}；RBF C∈{.1,1,10,100}、gamma∈{.01,.1,1,10}。先固定C看gamma、再固定gamma看C。Polynomial只用一个degree2概念对照。

在线性、RBF家族分别按验证balanced accuracy选配置，平分时较小C再较小gamma。记录后打开测试；测试仍用原训练186条拟合。教师已预跑测试用于确认可行性，课堂演示不宣称全新科研确认。不追加测试后调参。

线性2/||w||仅适用于指定输入空间；soft-margin参考带内允许有点。RBF分数等值线不是原二维平面的等距线。C增大在精确最优条件下总hinge不增、范数不减，但训练错误数、SV数与验证表现不保证同向变化。原生decision score没有概率解释。

## 时间与产出

第一课堂45分钟建立数据、几何、SV和soft margin定义；课间60–90分钟完成核心实验；第二课堂45分钟讨论C、核、尺度、保留集和适用条件。扩展扰动可选。

学生交付手算、少量对照图表与一页概念解释，引用至少两项实验，说明一个优势、一个局限及其条件。评分重点是定义、实验逻辑和机制解释。
