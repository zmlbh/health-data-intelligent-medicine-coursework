# 实验设计与可行性

## 一条学习主线

同一份真实数据承担两个角色：八条有意挑选的训练记录用于看清几何定义，完整训练/验证划分用于观察重叠数据下的方法行为。前者牺牲代表性换取概念清晰，后者防止学生把可分小图当作真实数据全貌。所有正式模型始终使用预先指定的两个输入。

## 问题与对照

| 问题 | 改变什么 | 固定什么 | 学生观察什么 | 能解释到哪里 |
|---|---|---|---|---|
| 都分对时如何选边界？ | 同一法向量的三个截距 | 八点、训练 scaler | 错误数、最小带符号距离 | 零训练错误不足以唯一确定边界 |
| 为什么分数要归一化？ | (w,b) 同乘正数 | 边界与点 | 分数和几何距离 | 决策分数的大小依赖表示 |
| 哪些点约束解？ | 分别删一个非 SV 和一个 SV | scaler、C、其余点、求解精度 | w、b、八点分数的改变量 | 当前拟合的约束作用，不是患者典型性 |
| hard margin 何时无解？ | 复制一点并给相反 y | 两点 x 完全相同 | 硬约束矛盾、soft margin 结果 | 构造证明，不宣称原数据有错标 |
| C 改变了什么？ | linear C=.01,.1,1,10,100 | 全训练、scaler、验证集 | 宽度、hinge、训练错误、验证表现 | 正则化与违例代价的权衡 |
| kernel 与 gamma 改变什么？ | 固定 C 看 gamma，再固定 gamma 看 C | 数据、scaler、评价规则 | 相似度、边界、训练/验证差距 | 灵活度机制，不能证明哪种核普遍更好 |
| 单位为何重要？ | x₁乘100，与是否标准化交叉 | 信息、划分、RBF C=1、gamma=.1 | 验证 decision score 差异 | 数值尺度改变距离，标准化抵消此单位变化 |
| 能否在新记录复现？ | 拟合记录换成保留记录 | 完整配置 | 混淆矩阵及分类指标 | 同源一次留出表现，不能外推临床效用 |

RBF 网格为 C∈{.1,1,10,100}、gamma∈{.01,.1,1,10}。先用单因素切片理解，再查看联合表，避免把网格搜索当作核心知识。Polynomial 只展示 degree=2、coef0=1、gamma=.1、C=1 的一个概念对照，不进行额外搜索。

扩展：以训练 SD 的 0%、5%、10%、20% 向验证特征加独立高斯扰动，非零水平重复100次、seed=9。不重新拟合模型；比较预测翻转比例。扰动分布是教学假设。

## 评价与冻结规则

先记录训练错误、hinge、支持向量数和线性宽度，这些量各有含义，不合成一个“优劣分”。再查看验证 confusion matrix、sensitivity、specificity、balanced accuracy 和 decision-score ROC-AUC。AB 比例较高，始终预测 AB 的 accuracy 已达 42/62，而 balanced accuracy 只有 .5。

为演示完整流程，在线性和 RBF 家族**各自**按验证 balanced accuracy 选一组配置，平分时取较小 C，再较小 gamma。目标不是选出跨家族冠军。冻结输入、划分、scaler、网格、选择规则和解释问题后才开测试。不增加阈值搜索，不启用 probability=True。测试阶段仍用原训练186条拟合，保持与验证实验的训练条件一致。教师预跑已查看过测试，本课只演示保留集协议，不宣称研究级全新确认。

## 已确认的可行性

`scripts/teacher_analysis.py` 已真实运行并检查收敛；所有实验可由保留的原档离线复现。

- 八点三个候选边界都零错误，最小带符号距离约 .383、.957、.383。
- 冻结 scaler 后，删远点 V072 不改变本次解；删 SV V061 改变原八点分数，最大差约 .427。
- 相反标签同坐标的构造无法满足 hard-margin 约束。
- 增大 linear C 时总 hinge 降低、线性参考带变窄，但验证表现没有持续提高。
- x₁乘100后，未标准化的最大验证分数差约1.538；标准化后约1.8×10⁻¹⁴。
- 测试函数默认不读测试标签；人工设置两个开关后才评价。

数值答案见教师参考；学生版只提供问题、操作入口和记录框架。

## 解释精度

1. Hard-margin 几何示例用 C=10000 的线性 SVC 近似求解，并核对所有 y·f≥1−10⁻⁵；不把这个参数说成原生 hard-margin 求解器。
2. 对固定输入和精确最优解，C 增大时总 hinge 不增加、||w|| 不减，因此线性参考带宽不增加。训练错误数、SV 数和验证指标没有同样单调保证。
3. Soft-margin 的 f=±1 是参考等值线，带内可以有样本。RBF 的这两条线在原输入平面上不是等距线，不能用二维宽度替代特征空间 margin。
4. 本次删除一个 SV 会改变解，不代表删任何 SV 都改变解；冗余约束、非唯一解和数值误差需要区别。
5. 原训练散点图先显示全范围，再对主要区域画边界；局部图注明显示范围外点数，这些点仍参与拟合。
