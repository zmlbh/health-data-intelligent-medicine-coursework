## D．C 怎样权衡间隔与违例？

线性 soft-margin 目标：

`min ½||w||² + C Σᵢ max(0,1−yᵢfᵢ)`。

第一项偏好较小的权重范数，对应较宽参考带；第二项惩罚训练违例。C 是两项的相对权重，不是噪声比例或概率阈值。

1. 运行前：C增大时，训练违例的代价怎样变？你预期总 hinge 和宽度怎样变？验证表现是否必须同步变化？

## E．Kernel 与 gamma 怎样改变相似度？

Kernel（核函数）给出某个特征空间中的内积。它允许 SVM 使用更丰富的特征关系，而不必显式展开全部坐标。

- Linear：`K(z,u)=zᵀu`。
- Polynomial：`K(z,u)=(gamma·zᵀu+coef0)^degree`，包含特征组合。
- RBF（Radial Basis Function，径向基函数）：`K(z,u)=exp(−gamma||z−u||²)`，按距离衰减相似度。

1. 两点相距1与2时，分别计算 gamma=.1 和1 的RBF相似度。较大 gamma 让影响更广还是更局部？
2. 固定 `C=1`，观察 gamma=.01、1、10 的边界。先预测形状，再运行 E。为什么不能同时改变 C 和 gamma 后，把全部变化归于其中一个参数？
3. 固定 `gamma=10`，比较 C=1、10、100 的训练与验证结果。训练贴合程度更高，验证表现是否持续提高？用局部影响与违例代价解释，不以“RBF好/坏”收尾。
4. 把 linear、一个degree=2的polynomial和RBF代表边界并列。描述各自允许表达的结构。本例两种非线性边界是否必须明显不同？
