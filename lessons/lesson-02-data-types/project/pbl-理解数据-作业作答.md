## 七、Q2 给数字赋予正确含义

**类型复核（选 3 个最易误判的字段）：**

1. **显影血管数 ca=0.0（计数）**：观察值是检查中显影的主要血管条数为 0；不允许直接解释为「没有做这项检查」或「病变数量为零」，因为 ca 有约 611 条空缺，空缺与 0 必须分开处理，且 0 与空缺的含义需要字典确认。
2. **胸痛类别 cp=4.0（名义类别）**：观察值 4 表示「无症状」这一类别名称；不允许解释为胸痛严重程度是 1 类的 4 倍，也不允许对 cp 求平均。
3. **最大心率 thalach=150.0（连续变量的整数记录）**：150 表示检查中达到的最大心率为 150 次/分，整数只是仪器与记录精度；不允许当成「发生 150 次」的计数，也不允许与年龄直接相减后当作绝对差值解释。

**顺序核查（2句）：** 不能把 0 至 4 直接当作统一疾病分期并求平均，因为表 B1 的总说明虽给出 0 至 4，但详细条目只解释 0 与 1，无法据此定义统一分期；需要一份明确写出各等级定义、严重程度排序与是否等距的编码说明（UCI 的 Additional Variable Information 或原始字典），才能判断该字段是否具备有序或等距关系。

**Q2 暂定结论：** 对 cp 采用指示变量编码（保留 1/2/3/4 四个类别信息，不合并、不改序），并注明其语义仍以 UCI 字典为准。

## 八、Q3 从研究问题选择方法

**均值与列联表（4行）：**

1. **年龄平均值 53.5 岁**：920 条记录的平均年龄，单位是年，表示该样本年龄的中心位置；因为年龄是连续量、整数只是记录精度，这个均值可以解释。
2. **胸痛编号平均值**：不宜计算也不可解释。cp 是名义类别，1 至 4 只是类别标签，其均值不代表任何中心位置，编号被重新命名均值就会改变而含义不变。
3. **num>0 的 0/1 平均值**：表示派生二分类分组中阳性所占比例，全表为 509/920 = 55.3%，单位是比例而不是数量。
4. **表 B3 的列联表**：比较的是胸痛类别 cp（4 个水平）与 num>0 二分类分组。使用卡方前仍需核实：各格期望频数是否足够、观察是否相互独立且类别互斥，例如 cp=1 一组只有 46 条记录（26 阴性／20 阳性），属于稀疏表，须考虑精确方法或有依据的合并。

**模型角色（4行）：**

1. **结局定义**：num=0 记为阴性、num>0 记为阳性，作为二分类结局；本课不拟合模型。
2. **一个数值预测变量**：年龄 age（连续量，920 条全部非空，可直接作为数值预测变量）。
3. **一个需类别编码的字段**：胸痛类别 cp（名义多分类，必须用指示变量，不能把编号当数值）。
4. **一个不应直接用于预测该结局的字段及理由**：num 本身不能作为预测变量，因为结局不能用来预测它自己（R3）；record_id 是标识符，也不应进入任何模型。

## 十、Q5 处理选择的代价

**筛选后果（3句）：** 表 D1 显示完整记录共 297+1+0+1=299 条，其中 Cleveland 占 297/299=99.3%，而原表中 Cleveland 只占 303/920=32.9%。也就是说删除全部缺失行会把「描述四中心患者」的任务实际变成「描述 Cleveland 单中心历史样本」，研究对象被悄悄替换，因此这个操作不足以支持以删除记录方式实现的选项 C。选项 C 应通过限制字段（例如跨中心分析不并入 chol）而不是限制或删除记录来实现。

| 候选操作 | 决定及理由；需检查或会停止的发现 |
|---|---|
| 删除全部缺失行 | 决定：不做。理由：表 D1 显示保留的 299 条中 Cleveland 占 99.3%，会改变研究对象。会停止的发现：若后续获得各中心完整数据或明确的缺失机制说明，可重新评估。 |
| 将可疑零值改为空缺 | 决定：先核实再决定，不直接改写。理由：R4 指出空缺不等于零，但 0 是否为「未记录」需要来源证据，不能凭推测改写。会停止的发现：若提供方确认 0 表示未记录则改为空缺；若确认 0 是真实测量则保留并说明。 |
| 将无序类别直接按编号当数量 | 决定：不做。理由：cp、thal 是名义类别，slope 虽有顺序但编号不等距，编号只是标签。会停止的发现：只有获得明确的等距定义后，才可考虑把 slope 按有序变量处理。 |
| 标准化数值特征 | 决定：暂不执行，仅在有依据时用于后续建模。理由：R5 指出标准化不修复缺失与来源偏差；若使用距离类或正则化方法，应先划分数据，再仅用训练部分估计均值与标准差。会停止的发现：若各中心分布差异来自来源而非尺度，标准化无法解决，须先核查来源。 |

**尺度复核（2句）：** 按 z=(x−均值)/标准差 核算，Cleveland 第 1 条记录年龄 z=(63.0−54.439)/9.024=8.561/9.024≈0.95（表 D2 保留三位为 0.949）。把胸痛类别重新编号（1,2,3,4 改为 10,20,40,80）后类别含义完全不变，但数值均值、标准差与最小最大值都会改变，所以任何按编号计算的均值、距离或回归系数都会随之改变，说明该字段的编号不是数量尺度。

| 单细胞 | 高维矩阵：3 位供者 × 100 个细胞 = 300 行（细胞）× 20,000 列（基因） | 供者编号与测序批次，且同一供者的多个细胞不能按独立患者处理 | 不能，表中没有细胞层级、供者编号或批次字段 |
| 影像 | 矩阵：20 位受试者 × 2 张 = 40 行（图像）× 4,096 列（64×64 像素，或同等降维特征） | 受试者编号（同一人 2 张图不独立）、图像预处理与采集参数 | 不能，表中没有图像或像素层级信息 |

**技术来源比较（3句）：** 表 D3 最后一行的两仪器均值差为 120−100=20（任意单位）。这种证据来自同一标准样本在两台仪器上的重复测量，因此差异可以直接指向仪器或流程造成的系统差异；而表 C2 的中心阳性比例差（Switzerland 93.5% 对比 Hungary 36.1%）只说明各中心结局构成不同，无法区分患者构成差异与技术差异。仍需核实的校准信息包括两台仪器的校准记录、测量时间、测量顺序与重复次数，缺少这些信息时不能把该差异判定为批次效应。

### 来源证据卡（5行）

1. **引用的说法：** 「该数据集共有 303 条记录」（常见于数据集页面摘要与二手介绍）。来源：UCI Heart Disease 数据集页面摘要／AI 回答（**请替换为你实际查到的来源**）；访问日期：2026-09-16。

### 数据使用建议书（约 430 字）

本表最终建议采用方案 C（限制使用）：保留四中心记录用于分中心描述，但限制字段与结局定义，不删除记录。

可描述对象为 Cleveland 303、Hungary 294、Switzerland 123、VA Long Beach 200 共 920 条历史记录。因 record_id 只是文件内行序号、没有跨中心身份核对表，且存在 2 条临床字段完全重复的记录，920 不等于 920 名患者，只能写「920 条记录」。

字段层面，age、trestbps、chol、thalach、oldpeak 是连续量，sex、fbs、exang 是二分类，cp、restecg、thal 是名义类别，slope 有序但不等距，ca 是计数；num 只在「0 对比大于 0」口径下含义明确（表 B1），0 至 4 不能当统一分期求平均。方法只做分中心描述统计与分类变量列联表，用卡方前须核实独立性与期望频数。

## 十三、第三阶段 翻转课堂与个人修订

**同伴质询记录（需按现场发言填写，下面是可套用的写法）：** 同伴引用表 C2 提出「Switzerland 阳性比例高达 93.5%，是否说明该中心应单独剔除」；其依据是表 C2 的 115/123。我仍不同意的点是：阳性比例差异只能说明结局构成不同，缺少采样框与仪器校准资料时无法区分患者构成差异与技术差异，因此不足以作为剔除中心的理由。

**个人修订（3句）：** 我改变的一项判断是把课堂初判的方案 D 改为方案 C，导致变化的证据是表 C1、C2 与 D1——证据不足不等于只能暂缓，可以先限制字段、保留记录地使用。这一改动对最终选项的影响是：从「停止使用」变为「有条件使用」，并新增了 chol 不进入跨中心比较这一操作约束。新证据并未推翻「不得直接合并全部字段」这一点，所以方案 A 始终被排除。

**最终退出条（2句）：** 我会带到未来科研的数据检查习惯是：拿到一张表先确认每一行代表谁、每一列测量了什么，再对每个零值和空缺分别写出「是否已核实其真实含义」（依据表 C1 与表 D1）。会使我暂缓分析的具体发现是：某个关键字段的零值或空缺在一整个中心里系统性出现，且无法取得其语义说明——这种情况下任何跨中心比较都不能开始。
