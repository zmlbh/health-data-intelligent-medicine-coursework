# 第 2 课 变量类型与数据类型

本项目围绕生物医学变量类型、缺失值、数据质量和预处理展开。

## 主要文件

- 数据与结果：`assets/pbl-understanding-data/`
- 数据字段：`assets/pbl-understanding-data/packet-b-data-dictionary.csv`
- Notebook：`notebook/pbl-understanding-data-lab.ipynb`
- 构建代码：`scripts/pbl-understanding-data-build.py`
- 完成版 worksheet：`v2_pbl-data-types-student-worksheet-已完成.docx`

## 运行方式

在 Jupyter 中打开并依次执行：

```text
notebook/pbl-understanding-data-lab.ipynb
```

运行结果用于说明变量类型、缺失模式、距离度量、PCA 和预处理边界。结论只适用于仓库中的教学数据。
