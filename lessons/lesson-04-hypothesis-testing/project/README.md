# 第五章 V3 学习材料

本目录与 `Hypothesis.md` 的学习目标配套，采用 V3 数据课的交付方式：

- `pbl-hypothesis-student-worksheet.docx`：发给学生的工作单；
- `pbl-hypothesis-teacher-reference.docx`：教师参考；
- `data/heart-disease-hypothesis.csv`：学生分析数据；
- `data/README.md`：字段、编码和数据边界；
- `lesson-plan.md`：45 分钟 PBL 教案；
- `review/`：教师专用数值核对，不能发给学生。

学生不应接收教师参考或 `review/`。数据为观察性、跨中心横断面资料，课堂结论只能表述为统计关联。
