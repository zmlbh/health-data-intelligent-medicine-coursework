# 第五章教案：统计检验与假设设计

本课使用四中心心脏病数据，把“治疗有效吗”改写为可检验的科学问题。学生先确定研究对象、比较对象和主要终点，再写 H0/H1，选择检验，报告效应量和置信区间，最后讨论混杂、多重比较和因果边界。

**课时**：45 分钟；课后作业 60–90 分钟。  
**数据**：`data/heart-disease-hypothesis.csv`，920 名受试者，四个中心。

## PBL 流程

| 时间 | 活动 | 产出 |
|---|---|---|
| 0–7 分钟 | 阅读情境，确定对象、比较对象、终点 | 问题框架 |
| 7–14 分钟 | 写 H0/H1，讨论双侧/单侧 | 假设卡 |
| 14–22 分钟 | 判断 Type I/II error，讨论 power | 错误类型判断 |
| 22–34 分钟 | 完成 5 个方法选择题 | 方法矩阵 |
| 34–40 分钟 | 讨论年龄、性别、site 的混杂和多重比较 | 限制清单 |
| 40–45 分钟 | 用“主张—证据—推理—边界”写退出卡 | 四句结论 |

主要问题：`disease=1` 与 `disease=0` 受试者的最大运动心率 `thalach` 是否不同？推荐双侧检验，因为题目问“是否不同”，方向应在查看数据前规定。

教师提示：这是观察性横断面资料，只能支持统计关联，不能推出因果。年龄、性别和 site 可能混杂；20 个指标中只报告一个显著结果会增加假阳性，应预先指定主要终点并考虑多重比较控制。

## 课后作业

另选一个生物医学问题，提交科学问题、H0/H1、变量类型、检验与备选方法、至少两个混杂因素、比较控制计划、效应量/CI/p/power 报告计划及结论边界。
