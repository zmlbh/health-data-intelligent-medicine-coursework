## 必须联网阅读的三份

这三份是可交互网页或在线书章节，做成 PDF 会丢掉主要价值，没有放进本目录：

- **R5中** 北京大学李东风《多元统计分析讲义》第8章 主成分分析
  https://math.pku.edu.cn/teachers/lidf/course/mvr/mvrnotes/html/_mvrnotes/mvr-pca.html
- **R7** 《Basics of Single-Cell Analysis with Bioconductor》第4章 Dimensionality reduction
  https://bioconductor.org/books/release/OSCA.basic/dimensionality-reduction.html
- **R8** Distill《How to Use t-SNE Effectively》 https://distill.pub/2016/misread-tsne/
- **R9** Google PAIR《Understanding UMAP》 https://pair-code.github.io/understanding-umap/

R8 与 R9 的核心是可以直接拖动参数看图形怎么变，务必在线打开。
