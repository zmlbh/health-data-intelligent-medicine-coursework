# 第 3 课 高维数据与降维

本项目演示高维数据中的距离集中、PCA 与 UMAP，并保留练习代码和课堂结果。用户提供的最终提交目录中没有本课正式提交版。

## 主要文件

- 数据：`student-package/data/`
- 课堂 Notebook：`student-package/notebook/pbl-high-dimension-reduction-classroom.ipynb`
- 运行代码：`analysis/scripts/run_classroom.py`
- 结果表：`analysis/results/classroom-seen-unseen.csv`
- 练习作答：`analysis/deliverable/pbl-high-dimension-reduction-student-worksheet-completed.docx`

## 运行方式

```bash
python -m pip install -r student-package/requirements.txt
python analysis/scripts/run_classroom.py
```

降维图只反映所用数据和参数下的结构，不能把二维图中的簇直接解释为确定的生物学类别。
