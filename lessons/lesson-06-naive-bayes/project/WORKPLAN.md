## 五、关键概念

### 5.1 从统计推断到预测

- 统计推断关注总体关联、效应及其不确定性，例如“腰痛是否与膀胱炎症有关联”。
- 预测关注未见样本上的误差，例如“根据一个新就诊者的症状，能否预测其疾病状态”。
- 两类问题可以使用相同变量，但研究目标、评价方式和结论边界不同。

### 5.2 数据模型与机器学习流程

监督学习模型可写成 $f_\theta:X\rightarrow\hat{Y}$。参数 $\theta$ 描述输入与输出之间的数学关系；分类模型常先输出 $P(Y=1\mid X=x)$，再通过阈值得到类别。

基本流程：

`数据输入 -> 定义 sample / feature / label -> 划分数据 -> 拟合模型 -> 产生预测 -> 选择阈值 -> 评价性能 -> 说明泛化边界`

| 概念 | 本课工作含义 |
|---|---|
| Sample | 一个独立观察对象，即数据表的一行 |
| Feature $X$ | 提供给模型的输入变量 |
| Label $Y$ | 希望模型预测的已知结果 |
| Training | 使用训练数据估计模型参数 |
| Prediction | 固定参数后，对新输入产生输出 |
| Generalization | 在未参与建模的新样本上仍保持性能 |

### 5.3 Train、validation 与 locked test

| 数据部分 | 主要职责 | 常见误用 |
|---|---|---|
| Train | 拟合模型参数 | 将训练表现当作泛化表现 |
| Validation | 选择模型、超参数和阈值 | 反复尝试直到得到偶然高分 |
| Locked test | 方案冻结后做一次最终评价 | 看完结果后继续修改模型 |

数据划分的目的不是形式上的“三份数据”，而是尽可能模拟模型面对未来未见样本的情形。

### 5.4 Loss

Loss 将单个预测与真实标签之间的差距表示为一个数。许多模型通过最小化平均 loss 进行训练，但训练目标不等于最终需要报告的全部评价指标。

- 二分类概率常用 cross-entropy：$`L=-[y\log p+(1-y)\log(1-p)]`$。
- 连续结局回归常用 mean squared error：$`L=(y-\hat y)^2`$。
- Bernoulli NB 主要通过计数估计先验和条件概率；仍可用 log loss 或 Brier score 检查其概率预测。

### 5.5 分类模型评价

固定阈值后先得到 TP、FP、FN 和 TN。不同指标回答不同问题：

| 指标 | 主要问题 | 主要局限 |
|---|---|---|
| Accuracy | 全部样本中分对多少？ | 可能掩盖类别不平衡和不同错误代价 |
| Sensitivity / Recall | 真阳性中找出了多少？ | 不说明阳性预测有多少是真的 |
| Specificity | 真阴性中排除了多少？ | 不说明漏诊情况 |
| Precision | 阳性预测中多少是真的？ | 会随患病率变化 |
| F1 | Precision 与 recall 的综合如何？ | 不使用 TN，不能代替完整错误分析 |
| ROC-AUC | 阳性是否总体排在阴性之前？ | 不确定具体阈值，也不评价校准 |
| PR-AUC | 阳性类别的 precision–recall 权衡如何？ | 基线依赖阳性率 |
| Calibration | 预测概率是否对应实际发生频率？ | 小样本估计可能很不稳定 |

Accuracy 等分类指标依赖选定阈值；AUC 概括跨阈值的排序；calibration 检查概率数值。三类证据不能互相替代。

### 5.6 Bayes theorem 与 Bernoulli Naive Bayes

对类别 $Y=c$ 和特征向量 $x$：

$$
P(Y=c\mid X=x)\propto P(Y=c)\prod_{j=1}^{p}P(X_j=x_j\mid Y=c)
$$

- Prior：观察当前特征前的类别概率。
- Likelihood term：给定类别后观察到某项特征的概率。
- Posterior：观察特征后的类别概率。
- “朴素”假设：给定类别后，各特征被视为条件独立。
- Laplace smoothing：避免训练数据中未出现的组合使整项概率变为零。

朴素贝叶斯的优点是简单、快速、适合小型二元特征或文本任务；主要风险是相关特征可能被重复计作独立证据，使 posterior 过度自信。

## 六、常见误区与失败模式

### 常见误区

1. Accuracy 很高就说明模型已经适合医学应用。
2. Sensitivity、recall 和 precision 是同一个概念。
3. ROC-AUC 高就说明阈值已经合理、概率也已经校准。
4. Test set 可以像 validation set 一样反复查看和调参。
5. 条件独立假设不成立，朴素贝叶斯就一定无法正确分类。
6. 模型输出 0.9 就等同于患者真实患病概率为 90%。

### 失败模式

1. 在 validation 或 test 结果上反复修改方案，造成乐观偏差。
2. 只报告 accuracy，不报告混淆矩阵和错误代价。
3. 将相关症状当成多份独立证据，得到过度自信的 posterior。
4. 用很小的内部测试集宣称总体 sensitivity 或 specificity 为 100%。
5. 将专家规则构造的教学数据误当成真实临床队列。
6. 忽略患病率、测量误差、标签误差和跨医院分布变化。

## 七、数据集与案例设计

选定数据集：UCI Acute Inflammations。

| 项目 | 内容 |
|---|---|
| 样本数 | 120 |
| 原始输入特征 | 6 项：体温和 5 项 yes/no 症状 |
| 主标签 | `bladder_inflammation` |
| 主标签分布 | 阳性 59，阴性 61 |
| 迁移标签 | `nephritis` |
| 缺失值 | 0 |
| 来源 | UCI Machine Learning Repository，DOI `10.24432/C5V59S` |
| 许可 | CC BY 4.0 |

预处理：将 `temperature_c >= 38` 转换为二元特征 `fever_ge_38`，其余症状转换为 0/1。

数据划分：stratified train / validation / locked test = 72 / 24 / 24，固定 `random_state=7`。

模型：`BernoulliNB(alpha=1.0)`；基线模型为只根据训练集类别比例预测的 prior-only baseline。

选择理由：数据规模小、医学语义直观、模型计算可手算，并且“规则化数据上的完美内部结果”能够形成有效冲突。学生必须区分模型是否正确复现数据规则与模型是否具有真实临床泛化能力。

## 十二、教师提示

- 先让学生试，再给概念和公式；不把“没学过”当作复习不足。
- 手算教学例子与UCI实际数据明确分开，不合并训练、不预告test满分。
- 让学生圈出每个条件概率和评价指标的分母。
- NB用计数估参，不把fit讲成梯度下降最小化validation损失。
- 不强求实际数据一定出现大幅过拟合；对照结果不同或相同都要解释。
- 条件独立不成立不意味着分类必然失败，分类全对也不代表概率完全可靠。
- 数据来源限制作为理解泛化的必要背景，不取代核心知识学习。
