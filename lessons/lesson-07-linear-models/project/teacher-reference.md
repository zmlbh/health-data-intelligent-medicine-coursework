# 第 8 讲教师参考

## 教学主线

本讲不从“哪个模型分数更高”开始，而从“两个模型各自把什么当成随机对象”开始。Logistic regression 直接建模 `P(Y|X)`，用交叉熵估计系数；LDA 建模 `P(X|Y=k)` 与先验，再用 Bayes rule 得到 `P(Y|X)`。两者都可有线性边界和 posterior，但概率的来源、假设和参数量不同。

## 核心答案

- Logistic 的参数是截距和系数，通常通过最大化条件似然或最小化二分类交叉熵估计。它不要求先为每一类完整指定 `X` 的分布，但要求 log-odds 与输入近似线性。
- LDA 估计每类均值、一个共享协方差矩阵和类别先验。给定类别的高斯密度与先验经 Bayes 归一化得到 posterior。共享协方差令类别比较中的二次项抵消，形成线性边界。
- 若特征维度为 d，二类 LDA 的均值参数约为 2d，共享协方差约为 d(d+1)/2，再加一个独立先验；若各类协方差不同，协方差参数约翻倍，边界变为二次，估计方差明显增加。Logistic 在编码后维度为 q 时约有 q+1 个自由参数。
- LDA 与 logistic 都能输出概率，但前者是生成式 posterior，后者是条件概率模型。概率来源不同意味着诊断假设、外推方式和受协方差估计影响的方式不同。
- AUC 描述排序区分，Brier/log loss 描述概率误差，sensitivity/specificity/FN/FP 描述阈值行动错误。分数不能互相代替。
- `5×FN+FP` 把漏诊代价设为误报五倍。阈值必须在 development 选择并冻结。
- OR 是在其他变量固定、单位和参照水平明确时的 odds 比，不是概率倍数。系数是条件关联，不自动是因果效应。
- 共线性可能让系数在 bootstrap 中大幅波动，而整体预测排序相对稳定；“预测稳定”和“解释稳定”是两个问题。

## 教师追问

当学生说“LDA 不能输出概率”时，要求写出密度、先验和归一化。当学生说“最大 OR 最重要”时，要求补充单位、参照、相关变量和区间。当学生说“LDA AUC 略高所以选 LDA”时，要求追问：生成式假设是否可信？概率校准如何？错误代价下的 FN/FP 如何？参数量是否适合样本量？

当学生说“假设不满足就必须弃用”时，要求他们比较假设偏离的程度、预测和校准证据、bootstrap 稳定性，以及替代模型的目标是否更符合任务。方法选择是条件判断，不是模型投票。

## 评分建议

建模对象、假设和目标 30；参数量与边界推理 20；无泄漏实验 15；概率/阈值评价 15；系数稳定与 CERB 边界 20。答案可不同，但必须把方法差异连接到数据条件和研究目标。
