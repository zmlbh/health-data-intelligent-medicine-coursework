# Linear Models：顶刊实证研究与高级图表阅读清单

筛选标准：2024–2025 年；`Nature Medicine` 正文研究论文；合法开放获取；与医学二分类、风险预测、模型验证或临床解释有关；正文必须包含可直接借鉴的多面板图。只保留正文 PDF，不含 Supporting Information。

## 推荐阅读顺序

1. **Clinical implementation of an AI-based prediction model for decision support for patients undergoing colorectal cancer surgery**（2025，DOI: 10.1038/s41591-025-03942-x）
   - 与作业最贴近：临床二分类风险预测、Logistic Regression、内部/外部验证和真实临床实施。
   - 可借鉴图：研究队列流程图、完整建模流程图、ROC、多队列校准曲线、风险分层、多面板临床结局图。

2. **Development and validation of a new algorithm for improved cardiovascular risk prediction**（2024，DOI: 10.1038/s41591-024-02905-y）
   - 重点：传统风险模型更新、性别分层、外部验证和临床决策价值。
   - 可借鉴图：森林图、不同风险因素下的预测曲线、决策曲线、男女分层校准图。

3. **Prediction of checkpoint inhibitor immunotherapy efficacy for cancer using routine blood tests and clinical data**（2025，DOI: 10.1038/s41591-024-03398-5）
   - 重点：临床变量建模、训练/测试与跨队列验证、模型解释。
   - 可借鉴图：端到端研究设计图、跨模型 AUC 气泡矩阵、风险分层生存曲线、混淆矩阵、SHAP/特征解释、多癌种外部验证。

4. **Proteomic signatures improve risk prediction for common and rare diseases**（2024，DOI: 10.1038/s41591-024-03142-z）
   - 重点：基线临床模型与新增变量后的增益比较，适合说明“更复杂模型不一定自动更好”。
   - 可借鉴图：研究设计图、跨疾病性能比较、风险增益点图、特征贡献与蛋白网络式多面板图。

5. **Primary care detection of Alzheimer’s disease using a self-administered digital cognitive test and blood biomarkers**（2025，DOI: 10.1038/s41591-025-03965-4）
   - 重点：二分类诊断、Logistic Regression、阈值选择，以及 sensitivity、specificity、PPV、NPV 的联合报告。
   - 可借鉴图：ROC、阈值性能点图、混淆矩阵、两阶段检测流程图、成本比较图。

6. **Cell-free DNA for the detection of kidney allograft rejection**（2024，DOI: 10.1038/s41591-024-03087-3）
   - 重点：Logistic Regression、OR、校准、ROC、决策曲线与外部验证。
   - 可借鉴图：亚型分层箱线图、ROC 对照、多变量结果表和外部验证性能图。

7. **Preeclampsia risk prediction from prenatal cell-free DNA screening**（2025，DOI: 10.1038/s41591-025-03509-w）
   - 重点：二分类风险预测、Logistic Regression、类别不平衡、灵敏度/特异度和外部队列验证。
   - 可借鉴图：样本筛选与建模流程图、多组学热图、多面板特征贡献图和外部验证 ROC。
