# 第 8 讲 线性模型、LDA 与 Logistic Regression

## 驱动问题

LDA 和 logistic regression 都可以给出线性分类边界和概率。它们究竟在**建模对象、概率来源、假设、优化目标和参数量**上有什么不同？面对一份小样本、混合变量类型的心脏病数据，怎样根据研究目标和数据条件选择方法，而不是先问“哪个模型更好”？

本工作单要求你建立一条方法选择推理链：先说明两种模型分别假设什么、估计什么，再观察这些差异怎样影响概率、边界、稳定性和错误代价。每项任务先写预想，再用 Notebook 证据修订。不要提前打开 locked test，也不要把模型系数直接写成因果效应。

## 数据与协议

本课使用 `data/heart.csv`，270 条记录，120 条阳性、150 条阴性。输入为 13 个混合类型变量，结局为 `heart_disease_present`。按主标签分层，以 `random_state=2026` 固定划分 80% development、20% locked test。development 内用分层交叉验证比较；所有标准化、one-hot 和模型拟合必须在训练折内完成。错误代价为 `5×FN+FP`。

## 任务 4：LDA 的假设与参数量
