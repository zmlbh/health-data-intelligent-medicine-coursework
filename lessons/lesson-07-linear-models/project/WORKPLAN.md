# 第 8 讲学习计划：线性模型、LDA 与 Logistic Regression

主题：简单模型为什么仍然重要？


## 一、课程定位

本讲面向生命科学专业、即将进入大四并准备交叉学科直博的学生。学生修读过微积分和数理统计，也完成了前七讲，但不默认保留完整的矩阵、概率分布或算法背景。

本讲不把 LDA 和 logistic regression 简化为两个 API，也不要求学生背诵矩阵推导。教学目标是在一个有真实决策冲突的生物医学案例中，用适量数学解释模型为何工作、概率从何而来、公式中的每个量怎样影响结论，再通过分阶段证据审计训练独立判断。

教学形式为个人完成的 PBL Notebook：第一课堂提出问题并建立学习需求；课后自学、运行和作答；第二课堂学生讲授学习到的知识和分析结果。教师讲授主要PBL 问题的讲解。

## 二、核心问题与驱动问题

核心问题：

1. 什么是线性评分和线性分类边界？
2. Logistic regression 如何把任意实数评分转换为 0–1 概率？
3. LDA 为什么从类条件高斯分布出发，最后也得到线性边界和后验概率？
4. LDA 与 logistic regression 的真正差异是“能否输出概率”，还是概率的来源与假设？
5. Logistic 系数、odds 和 odds ratio 应怎样解释？
6. 为什么 AUC、概率校准和固定阈值下的错误后果不能互相替代？
7. 共线性、特征尺度、类别不平衡和变量选择会怎样改变预测与解释？
8. 为什么模型关联不能自动写成因果结论？

驱动问题：

> 对一组小样本、混合变量类型的心脏病数据，应如何在 LDA 与 logistic regression 之间作出可辩护的选择，并依据验证性能、概率校准、错误代价、模型假设和系数稳定性，判断哪些结论可以报告、哪些结论会失败？

病例冲突：分析员 A 因 LDA 的内部 AUC 略高而主张选择 LDA；分析员 B 声称只有 logistic regression 能输出概率，并准备把最大 OR 写成独立致病因素；负责人要求所有模型统一使用 0.5 阈值，而项目又规定漏诊代价是误报的 5 倍。学生必须学习通过分析，回答这些问题。

## 三、学习目标

完成本讲后，学生应能够：

1. 用 $z=\beta_0+\mathbf{x}^T\boldsymbol\beta$ 解释线性评分、权重和决策边界。
2. 用 sigmoid、odds 和 logit 说明 logistic regression 如何输出二分类概率。
3. 解释 $\mathrm{OR}=e^{\beta_j}$ 的尺度、参照水平和“其他变量固定”条件，并区分 odds 与 probability。
4. 从 $\mathbf{X}\mid Y=k\sim\mathcal N(\mu_k,\Sigma)$ 出发，说明 LDA 的均值、共享协方差和先验各自承担什么作用。
5. 看懂共享协方差使二次项抵消、从而得到线性边界的核心推导。
6. 区分 linear regression、logistic regression 和 LDA 的结局、建模对象、输出及假设。
7. 建立避免预处理泄漏的 pipeline，并区分开发集与 locked test 的职责。
8. 综合 ROC-AUC、PR-AUC、sensitivity、specificity、Brier score、校准与 bootstrap 区间评价模型。
9. 依据漏诊与误报的相对代价在开发数据上选择并冻结阈值。
10. 用系数 bootstrap 和近重复变量压力测试说明“预测稳定”不等于“单个系数稳定”。
11. 用 Claim–Evidence–Reasoning–Boundary（CERB）结构写出模型选择和结论边界。

## 四、数学与概念骨架

### 4.1 共同的线性评分

两种模型最后都比较一个形如 $a+\mathbf{x}^T\mathbf{w}$ 的分数。权重决定各特征对评分的方向和相对贡献，但其数值依赖变量单位、标准化、分类参照和同时进入模型的其他变量。

### 4.2 Logistic regression

$$
z=\beta_0+\mathbf{x}^T\boldsymbol\beta,
\qquad
p=P(Y=1\mid\mathbf{x})=\frac{1}{1+e^{-z}}
$$

反向写为：

$$
\log\frac{p}{1-p}=z
$$

若其他变量固定，$x_j$ 增加一个建模单位，odds 乘以 $e^{\beta_j}$。这不是“概率乘以 $e^{\beta_j}$”，也不是自动成立的因果效应。二分类交叉熵

$$
-\left[y\log p+(1-y)\log(1-p)\right]
$$

会对“高置信度但错误”的概率预测给予较大惩罚。

### 4.3 LDA

LDA 先建模每个类别中的特征分布：

$$
\mathbf X\mid Y=k\sim\mathcal N(\boldsymbol\mu_k,\boldsymbol\Sigma),
\qquad P(Y=k)=\pi_k
$$

去掉类别间相同的常数后，判别分数为：

$$
\delta_k(\mathbf x)=
\mathbf x^T\boldsymbol\Sigma^{-1}\boldsymbol\mu_k
-\frac12\boldsymbol\mu_k^T\boldsymbol\Sigma^{-1}\boldsymbol\mu_k
+\log\pi_k
$$

$\Sigma^{-1}$ 根据噪声大小和特征相关重新加权距离。因为各类共享同一个 $\Sigma$，高斯对数密度中的 $\mathbf{x}^T\Sigma^{-1}\mathbf{x}$ 二次项在比较两类时抵消，剩下线性边界；若每类使用不同协方差，则得到 QDA 式二次边界。LDA 通过 Bayes rule 计算 posterior probability，因此“只有 logistic 能输出概率”是错误的。

### 4.4 从概率到医学决定

概率阈值 $t$ 对应线性评分阈值 $\log[t/(1-t)]$。把阈值从 0.5 降到 0.2，评分阈值从 0 降到约 $-1.386$，通常会减少 FN、提高 sensitivity，同时增加 FP、降低 specificity。阈值应连接错误代价、资源和目标人群，不能由软件默认值替代。

## 五、关键误区与失败模式

### 常见误区

1. LDA 不能输出概率，logistic regression 才可以。
2. AUC 略高就说明模型更适合临床使用。
3. 概率阈值 0.5 是自然且普遍正确的选择。
4. OR=2 表示患病概率翻倍。
5. OR 最大的变量就是最重要的致病变量。
6. LDA 的正态性假设有偏离，就必须机械弃用模型。
7. 预测 AUC 稳定就说明所有回归系数也稳定。
8. 在全数据上标准化后再交叉验证不会泄漏信息。

### 失败模式

1. 在 locked test 上重新选择模型或阈值。
2. 只报告 AUC，不报告校准和特定阈值的错误类型。
3. 忽略连续变量尺度、分类参照和共线性，直接比较系数大小。
4. 将小型内部测试集的点估计写成普遍性能。
5. 将观察性回归中的条件关联写成因果效应。
6. 在类别不平衡或错误代价不对称时仍机械使用 accuracy 与 0.5 阈值。

## 六、数据集与固定分析协议

选定数据集：UCI Statlog (Heart)。

| 项目 | 内容 |
|---|---|
| 样本数 | 270 |
| 原始特征 | 13 项，含连续、二元、名义和有序/计数变量 |
| 结局 | `heart_disease_present`，1=存在，0=不存在 |
| 类别分布 | 阳性 120，阴性 150 |
| 缺失值 | 0 |
| 来源 | UCI Machine Learning Repository，Statlog (Heart) |
| 许可 | CC BY 4.0 |

分析协议：

- stratified 80% development / 20% locked test，`random_state=2026`；
- 连续变量在每个训练折内标准化，分类变量在训练折内 one-hot；
- 重复分层交叉验证比较 LDA、logistic regression，并设置 Gaussian NB 和 prevalence baseline；
- 以 $5\times FN+FP$ 作为本案例的错误代价；
- 用 bootstrap 表示测试指标和 logistic 系数的不确定性；
- 用偏态、协方差差异和近重复年龄变量进行假设与共线性压力测试。

## 七、总体学习顺序

`病例触发与初始判断 -> 恢复公式所需的符号与直觉 -> 数据审计 -> 开发集比较 -> LDA 假设与 logistic OR 审计 -> 代价阈值 -> locked test -> CERB 修订 -> 新数据迁移`

公式不单独作为讲授终点。每个数学对象都按照“符号是什么—公式做什么—怎样改变预测—它不能支持什么”四步回到决策问题。


## 十二、评价要点

- 能解释公式中每个关键符号，而不是只复制定义。
- 能把公式与一个具体预测、OR 或阈值后果连接起来。
- 能区分两种模型的概率来源与线性边界来源。
- 能使用无泄漏的开发/测试流程，并说明 locked test 为何只能最后打开。
- 能同时解释区分、校准、错误类型和不确定性。
- 能识别共线性导致的系数不稳定，而不误判为预测必然失效。
- 能依据错误代价选择阈值，不机械使用 0.5。
- 最终结论遵循 CERB，并明确内部预测、临床部署、变量关联和因果解释之间的边界。

## 十三、教师实施提示

- Notebook 中只有黄色 `student-response` 单元需要学生填写；蓝色说明区用于阅读，绿色运行区用于生成与审计证据。
- 教师完整版已填写一种参考答案，评分应重视推理链与边界，不要求学生逐字复现。
- 公式先解释输入、输出和方向，再进入符号；LDA 二次项抵消属于挑战层，不要求背诵矩阵求导。
- 不提前展示 Packet D；否则学生无法体验证据逐步改变判断的过程。
- 不把“假设不完美”教学成机械二选一，应继续检查预测、校准和稳健性。
- 不把“可解释模型”教学成“系数天然具有因果解释”。


## 十五、收束问题

> 当两个线性模型都给出约 0.91 的 AUC 时，我能否说明它们的概率从哪里来、0.5 阈值为何可能错误、一个 OR 依赖哪些条件、哪些假设正在承受压力，以及为什么这份内部结果仍不能证明因果作用或临床有效性？
