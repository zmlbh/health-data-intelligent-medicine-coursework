# 第 8 讲 PBL 实验设计

## 核心设计

实验不把 LDA 和 logistic regression 当作两个候选商品，而把它们当作两种不同的概率建模方案。学生先填写“对象—参数—目标”表，再运行同一份数据。所有结果都要回到四个问题：模型假设什么、估计多少参数、概率从哪里来、这些差异何时影响选择。

| 核心知识 | 问题活动 | 产出 |
|---|---|---|
| 建模对象 | 比较 `P(Y|X)` 与 `P(X|Y)P(Y)` | 两条概率来源流程 |
| 优化/估计目标 | 写出 logistic 交叉熵和 LDA 类条件似然 | 目标函数对照 |
| 参数量 | 计算 one-hot 后 logistic 系数与 LDA 均值/协方差数量 | 参数规模表 |
| 线性边界 | 解释 sigmoid 与 LDA 二次项抵消 | 边界推理 |
| 方法选择 | 用假设压力、样本量、概率目标和错误代价解释选择 | 条件式选择规则 |
| 预测评价 | 比较 AUC、校准、FN/FP 和代价 | 开发集证据表 |
| 解释稳定 | bootstrap 与近重复变量 | 系数—预测稳定性对照 |

## 时间安排

第一次课堂 45 分钟：驱动问题、任务 1–4，重点讨论两种模型的对象、参数和假设。课后 60–90 分钟：Notebook A–C，完成无泄漏流程、开发集比较、阈值和稳定性实验。第二次课堂 45 分钟：任务 7–9，提交冻结方案后打开 locked test，最后用 CERB 说明方法选择的条件和边界。

## 固定协议

数据为 270 条记录，120 阳性、150 阴性；13 个混合类型输入。分层 80/20，`random_state=2026`。连续变量在训练折内标准化，分类变量在训练折内 one-hot。模型为 prevalence baseline、Gaussian NB、LDA 和 logistic regression。错误代价为 `5×FN+FP`。测试指标和系数使用 bootstrap 区间。

比较不以单一分数决定。至少同时检查：模型对象与假设、参数数量相对样本量、ROC-AUC/PR-AUC、Brier/log loss、固定阈值 FN/FP、校准和系数稳定性。测试集只在方案冻结后打开。

## 结论边界

实验支持在给定数据协议和目标下说明方法选择理由，不支持因果效应、临床部署或跨医院外部有效性。模型系数是条件关联，受单位、参照、共线性和样本量影响。
